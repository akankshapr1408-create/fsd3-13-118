## FS(file system):
this is the library of node
interact directly with operating system
file handling
it direct connect with client OS rather than browser
## Major task of FS Module
- Reading and writing files
   - readFile()
   - writeFile()
   - appendFile()
- Directory Management 
   - mkdir()
   - rmdir()
   - rm()
   - readdir()
- Metadata/Information
   - stat()
   - lstat()
   - fstat()
- Watchinf for changes
    - watch()
    - watchFile()
    - unwatchFile()
- Streaming large files
   - createReadStream()
   - createWriteStream()
- File operations
   - rename()
   - truncate()
   - unlink()
   - link()
   - syslink()
